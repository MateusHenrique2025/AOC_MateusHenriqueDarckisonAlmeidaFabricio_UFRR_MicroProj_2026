# Como Reproduzir o Projeto

Para executar a simulação completa e gerar todas as métricas e ondas automaticamente, siga os passos abaixo:

## 1. Pré-requisitos
Certifique-se de que tem o ambiente Linux (Ubuntu / WSL) e as ferramentas necessárias instaladas:
```bash
sudo apt update
sudo apt install ghdl gtkwave

```

## 2. Clonar e Aceder ao Projeto

Clone o repositório e navegue até à pasta raiz:

```bash
cd ~/microproj

```

## 3. Executar o Script de Automação

Atribua permissão de execução ao script e execute-o para rodar todas as simulações:

```bash
chmod +x run_all.sh
./run_all.sh

```
